# 🌍 NGO-Connect

**AI-Powered Real-Time Volunteer Coordination Platform for Social Impact**

NGO-Connect is a real-time humanitarian coordination platform that bridges the gap between NGOs and volunteers. It leverages Artificial Intelligence, location-based services, and proof-based verification to enable efficient task allocation, team collaboration, and transparent impact tracking.

---

## 🚀 Features

### 🏢 NGO Dashboard

* Upload reports in text or image format
* AI-powered task analysis using Gemini
* Monitor previous uploads
* Track ongoing tasks
* Release stalled tasks
* Verify task completion proofs
* Approve or reject submissions

### 👤 Volunteer Dashboard

* Skill-based onboarding
* AI-powered task recommendations
* Find nearby opportunities
* Accept tasks individually or request teams
* AI-generated preparation checklists
* Navigation support using maps
* Real-time progress tracking
* Leaderboards and badges

### 👥 Dynamic Squad Formation

* Team requests for large missions
* Notification system for nearby volunteers
* Radius-based volunteer discovery
* Team size control
* Leader responsibility mechanism
* Collaborative mission execution

### 🤖 AI Mission Control

* Context-aware chatbot assistant
* Intelligent guidance for volunteers
* Task difficulty analysis
* Equipment recommendations
* Automated checklists

### 📸 Proof-Based Verification

* Photo upload for task completion
* NGO review and approval system
* Transparent validation workflow

### 🏆 Gamification

* Points and badges
* Contribution history
* Global leaderboard
* Impact tracking

---

# 📌 Problem Statement

During emergencies and social crises, NGOs often struggle with volunteer coordination, task verification, and efficient resource allocation. Manual processes lead to delays, poor transparency, and reduced impact.

NGO-Connect addresses these challenges by providing an AI-powered platform that enables real-time collaboration between NGOs and volunteers.
